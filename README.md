# LaChaza
La página web de LaChaza facilita la compra de hamburguesas artesanales en la Uniagustiniana Tagaste, Bogotá, ofreciendo un servicio rápido, intuitivo y sin filas. Los clientes pueden seleccionar sus productos, realizar pedidos en línea y recibir un ticket con su número de orden para recoger su compra cuando esté lista.
